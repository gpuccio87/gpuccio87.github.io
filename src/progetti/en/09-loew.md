Loew is an evolutionary algorithm built and optimized to work together with <a class="ajax-page-load" href="#portfolio/portfolio-8.html">Golem</a>, for creating, testing, analysing and then evolving an artificial intelligence. The algorithm creates multiple instances of a neural network, each with different characteristics, to test which ones are the most efficient (in terms of results and/or timing). It then makes small changes to the best ones (thus creating "evolutions" of them) and starts the tests again. The goal is therefore to find, heuristically, the best neural network configuration for a given task.
