An automation for Claude that runs the weekly Todoist review according to a personal GTD system. It finds tasks without a type label, those stuck in the Inbox and those with inconsistent labels, proposes the right project and labels in batches (task type, verb, context, status, deadline, lead time), applies the changes only after confirmation and wraps up with a report and a few questions to reflect on the week.
