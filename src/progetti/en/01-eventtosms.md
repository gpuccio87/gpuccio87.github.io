EventToSMS is an Android script, built with Tasker and Javascript, that sends clients on the calendar an appointment reminder, completely automatically. Every day the script checks the next day's calendar, looks up the contact in the address book (adding it if it isn't there) and sends a reminder SMS with the date and time of the appointment. Finally, the script sends an email to report whether it managed to send all the texts or whether it needs more information.
