AnnA stands for Artificial Neural Network A. It's a neural network (in everyday language, an artificial intelligence), written in Python, that can learn and carry out tasks. When it is created, you can set the number of input, hidden and output neurons. Unlike <a class="ajax-page-load" href="#portfolio/portfolio-8.html">Golem</a>, it is written without third-party libraries such as Tensorflow. It was tested in the <a class="ajax-page-load" href="#portfolio/portfolio-10.html">TicTacToe AI</a> project.
