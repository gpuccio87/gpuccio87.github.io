Loew es un algoritmo evolutivo creado y optimizado para trabajar junto con <a class="ajax-page-load" href="#portfolio/portfolio-8.html">Golem</a>, para la creación, la prueba, el análisis y la posterior evolución de una inteligencia artificial. El algoritmo crea múltiples instancias de una red neuronal, con características distintas, para comprobar cuáles son las más eficientes (en términos de resultados y/o de tiempos). Después aplica pequeñas modificaciones a las mejores (creando así unas "evoluciones") y vuelve a empezar las pruebas. El objetivo es, por tanto, encontrar de forma heurística la mejor configuración de una red neuronal para una tarea concreta.
