Todoist Auto es un script para Google Assistant y Android, creado con Tasker, Javascript, Actions on Google y las API de Todoist. El script permite invocar una Action de voz con Google Assistant (en smartphone, Wear OS, Android Auto, Google Home mini, etc.) para añadir tareas en Todoist. Según la frase, las tareas se añaden en proyectos distintos o con etiquetas distintas (por ejemplo "Recuérdame antes de salir...", "Recuérdame cuando vuelva a casa...", "Recuérdame llamar a...". Además, al conectarse al bluetooth del coche, el script lee en voz alta todas las tareas del filtro "En el coche" de Todoist.
