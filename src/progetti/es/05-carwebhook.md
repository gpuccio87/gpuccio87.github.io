CarWebhook es un script para Android, creado con Tasker y Javascript, que guarda en el dispositivo y envía a un webhook (integrando este dato, por ejemplo, en el sistema domótico) el lugar donde se aparcó el coche por última vez y cuántos km se recorrieron en el último viaje. El script se activa al conectarse y desconectarse del sistema bluetooth del coche. En el momento de aparcar aparece una notificación en el smartphone para encontrar el coche aparcado. Los kilómetros recorridos se calculan mediante las API de OpenStreetMap. Este último dato es útil, por ejemplo, para calcular el consumo.
