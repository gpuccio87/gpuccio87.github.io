AnnA è l'acronimo di Artificial Neural Network A. E' una rete neurale (nel linguaggio comune un'intelligenza artificiale), scritto in Python con la capacità di imparare ed eseguire compiti. In fase di creazione si possono definire numero di neuroni di input, hidden e output. A differenza di <a class="ajax-page-load" href="#portfolio/portfolio-8.html">Golem</a>, è scritta senza l'utilizzo di librerie di terze parti come Tensorflow. E' stata testata nel progetto <a class="ajax-page-load" href="#portfolio/portfolio-10.html">TicTacToe AI</a>.
