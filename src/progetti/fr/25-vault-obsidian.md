Une automatisation pour Claude qui contrôle et met de l'ordre dans les notes d'Obsidian via sa Local REST API. Elle trouve les tags incohérents, les requêtes cassées, les liens vers des notes jamais écrites, les doublons, les fichiers de conflit de synchronisation, les projets à l'arrêt depuis longtemps et les notes sans statut ni sujet, et propose comment les corriger.
