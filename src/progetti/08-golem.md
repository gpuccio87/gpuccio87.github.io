Golem è una rete neurale scritta in Python grazie alla libreria Tensorflow; ha la capacità di imparare ed eseguire compiti. In fase di creazione si possono definire numero di neuroni di input, hidden e output. E' stata creata ed ottimizzata per lavorare assieme a <a class="ajax-page-load" href="#portfolio/portfolio-9.html">Loew</a> ed è stata testata in <a class="ajax-page-load" href="#portfolio/portfolio-10.html">TicTacToe AI</a>.
